# Synthetic worked example

Every JSON file in this directory is invented training/contract material. None is extracted from the Kazakhstan NDC/NAP or any government document. Country naming is only to demonstrate attribution. These files must never enter the production source corpus, release history or public dashboard.

`synthetic-input.json` supplies three original segments, including Russian text. `translation.json` demonstrates a complete aligned English layer. `extraction.json` shows labels, a conditional target, an institution, a support need and DRR context. `prime-report.json` demonstrates required sections and explicit source gaps. The examples are generated by `scripts/build_v2_examples.py`.

The application assigns stable production IDs; the example uses local IDs to make links readable. The offline validator checks selected invariants, not every semantic claim or translation. A source-oriented model challenge, full bundle validation and production transports remain separate implementation work.
