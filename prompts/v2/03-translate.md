# Complete aligned English reading layer

Use translation.schema.json. Return one entry per owned segment, keeping segment IDs, headings, table rows/columns, units, footnotes and conditional language. Neighbor segments supply context but are not duplicated as owned outputs. Preserve numeric tokens and dates, negation, modality, institution names and policy terminology. Do not summarize.

For English originals use identity. Use official_parallel only when the input includes a verified equivalent English segment; reference that exact supplied segment ID. Otherwise translate and label machine_translation. Do not invent a parallel segment or replace a conflicting original silently. Record terminology decisions and uncertainty; an unreadable source cannot be recovered by plausible translation.

Separate advisory `notes` from blocking `quality_flags`. Notes retain declared sample/batch scope, source formatting artifacts that were faithfully preserved or resolved, contextual terminology choices and source ambiguities preserved without inventing a resolution. A source-stated numeric difference across editions is a note, with both values retained; it is not itself a translation defect. Use quality_flags for unresolved fidelity or coverage defects within the supplied owned text, such as illegible content or uncertainty that prevents a faithful rendering. Never clear a genuine defect merely to pass validation.

When `task_context.source_coverage` already declares missing or clipped original material, translate the readable supplied owned text faithfully and retain that upstream limitation in notes. Do not reconstruct absent wording. An already-declared gap in the original is not, by itself, a translation quality_flag, and a faithful reading layer does not upgrade source coverage. Still flag omitted or altered supplied text, unsupported numbers or conditions, or uncertainty that prevents faithful rendering of the supplied text. Preserve clipped labels as clipped.

The application verifies every owned segment is represented, stores alignment and hashes, and checks the English layer before downstream use. Each call covers its owned segments; the application accounts for all batches in a full-document job. An explicitly declared page-text evaluation must retain its limits in notes and must not claim full-document coverage. Translate all supplied source content, including relevant notes and tables, not only cited targets; retain any declared upstream gaps without claiming complete original-document coverage. Missing or unfaithfully rendered supplied owned text remains a blocking defect.

Set source_language for each segment using a language code (for example en, ru or tr), mul for mixed-language segments, and und only when genuinely undetermined. Preserve English segments with exact identity even inside multilingual documents. Document-level language lists must not replace segment language identification.
