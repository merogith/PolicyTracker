## Debugging completed

- Connection recovery keeps model controls locked while a restored request is active, then releases them at completion. A restarted session clears stale request/sign-in state.
- One transient loopback connection reset occurred on the initial smoke attempt. The full rerun passed without retries. The client now retries a failed **read** once; it never automatically repeats a write or billable model request. Both boundaries have regression tests.
- A second server launch on an occupied port cannot initialize the country worker or change the running server's saved job state. HTTP tests now use an isolated temporary profile store.
- API connection tests reject a response with the wrong model or reasoning effort, using the same verification rule as structured generation.
- Generated profile provenance and proposed source/conflict links render correctly in the current interface; the full profile rendering tests pass.
